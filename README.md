# Tarea 02: Variables, Condicionales y Tipos de Datos en Python

Este directorio contiene la resolución de los ejercicios prácticos de lógica de programación en Python mediante Google Colab.

## Contenido del cuaderno (`tarea_02.ipynb`)

1. **Problema 1 - Clasificador de temperatura:** Bucle numérico de -30 a 50 con categorización climática (`Muy frío`, `Templado`, `Caluroso`).
2. **Problema 2 - Números especiales del robot:** Filtro de divisibilidad por 5 y 10 en un rango del 1 al 100 usando el operador módulo (`%`).
3. **Problema 3 - Detector de puntaje gamer:** Captura dinámica de dos puntajes mediante `input()`, suma aritmética y clasificación de niveles por rangos numéricos.
4. **Problema 4 - Calculador de perfil musical:** Estructura condicional múltiple evaluando edad y preferencias mediante operadores lógicos booleanos (`and`, `not`).

Todos los bloques de código se encuentran comentados línea por línea y ejecutados con sus respectivas salidas en pantalla.
